# muse* // 



Muse* is an AI powered creative director that takes your raw, unpolished, half-baked project ideas and immediately gives them a visual pulse. We completely abandoned strict lines, padding borders, and rigid grids to let heavy typography, messy hand-drawn doodles, and vast fields of naked whitespace do the actual talking. 

## Tech Stack:

* **The Skeleton:** React and Next.js handling lightweight page components that adapt smoothly as you scroll.
* **The Paint:** Pure Tailwind CSS locked down to absolute zero-radius corners and flat, aggressive chunks of primary colors (no gradients allowed).
* **The Tension:** An almost chaotic mix of conflicting Google fonts—pairing a heavy display font (Konkhmer Sleokchher) against a messy brush script (Yuji Boku) and loose, lazy handwriting (Nothing You Could Do). 
* **The Logic:** A highly descriptive inline JavaScript theme parser that reads the specific "soul" of your prompt keywords, immediately morphing the entire website's design architecture and color layout tokens in real-time.

## The Big Picture

Because muse* turns standard text prompts straight into functional, code-ready CSS variables and layout modules, it is way more than a visual playground. It behaves like a true, rapid creative director—giving indie hackers, designers, and builders a striking, unforgettable visual anchor for their projects in under three seconds.
